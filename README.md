# 🥋 Bandung Karate Club - Cabang Tulang Bawang

Website organisasi karate modern dan profesional untuk **Bandung Karate Club Cabang Tulang Bawang** yang dibangun menggunakan **Next.js 14**, **Tailwind CSS 3.4**, dan **TypeScript**.

Project ini dibuat sebagai website profil organisasi karate yang menampilkan informasi dojo, pelatih, kegiatan, galeri, jadwal latihan, dan pendaftaran anggota secara modern dan responsive.

---

## ✨ Features

* ✅ Modern Landing Page
* ✅ Responsive Mobile-First Design
* ✅ Dynamic Dojo Pages (`/dojo/[slug]`)
* ✅ Modern Navbar & Footer
* ✅ Trainer/Sensei Section
* ✅ Event & Activities Section
* ✅ Gallery with Modal Preview
* ✅ Schedule Table with Filter
* ✅ Registration Form Validation
* ✅ Contact Form
* ✅ SEO Metadata & Open Graph
* ✅ Reusable Components Architecture
* ✅ Tailwind CSS 3.4
* ✅ Framer Motion Animation
* ✅ TypeScript Support

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/IKetutWidiyane/karate_profile.git
```

---

## Masuk ke Folder Frontend

```bash
cd karate_profile/frontend
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

Website akan berjalan di:

```bash
http://localhost:3000
```

atau port lain jika 3000 sedang digunakan.

---

# 🧩 Build Production

```bash
npm run build
```

---

# ▶️ Run Production Server

```bash
npm start
```
