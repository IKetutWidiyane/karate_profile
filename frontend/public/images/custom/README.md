# Foto Custom

Simpan foto pribadi Anda di folder ini.

Contoh:

- `dojo-menggala.jpg`
- `pelatih-andri.jpg`
- `kegiatan-ujian.jpg`
- `galeri-latihan.jpg`

Untuk memakai foto di website, ubah nilai `image` di `frontend/src/data/site.ts`.

Contoh:

```ts
image: "/images/custom/dojo-menggala.jpg"
```

Format yang disarankan: `.jpg`, `.jpeg`, `.png`, atau `.webp`.
